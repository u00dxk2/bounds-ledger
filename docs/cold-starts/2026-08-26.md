### There is a new gate on the rail, and its counter is easy to misread

`scripts/check-deferrals.mjs` (A-25) now runs inside `npm run check`, so it is part of the day's
first gate. It prints **`N declared deferral(s)`**.

**That is a measure of ADOPTION, not of inventory.** It counts deferrals that have declared
themselves with `deferral: true` plus an `expiresOn` and a `releaseTest`. A deferral still
written as a sentence in a note field is invisible to it — which is exactly the population the
gate exists because we could not track. Today it reads 1. Read a rise as better coverage, not as
more debt, and do not report the bare figure as "outstanding deferrals".

It fires on **expiry** and on **malformedness** and is silent on a well-formed unexpired
deferral however many exist. That silence is deliberate: a check that is red whenever anything
is outstanding is the permanently-red alarm this lane was founded on. Do not "improve" it into
firing on existence.

`npm run deferrals` adds the pull-request leg, which needs `gh` and **exits 2 rather than 0**
when it cannot run. That leg is deliberately off the CI rail for that reason.
