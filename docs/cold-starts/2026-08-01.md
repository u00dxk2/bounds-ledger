### New standing rule as of today — read before shipping any detector

**`W-4` / KP-78: prove the instrument can fail.** Ship no test, guard, lint, probe, `--check` mode or alarm
without demonstrating at write time that it returns BOTH answers — fires when the condition is present, silent
when absent — and put both outputs in the finding or commit. **Prove the mutation landed with
`git diff --numstat` before believing any negative control**: a control written with `\n` against CRLF files
silently no-ops, which is exactly how a working pipefail guard got pronounced broken on 2026-07-25.

The 7/31 audit's most valuable output was not a fixed detector but a **missing** one — A-8's own fix (a
hand-added CI step) had nothing asserting it stays. **Apply the rule to recent commits, not just to files that
look like tests.** Full account: `docs/findings/2026-07-31-kp78-prove-the-instrument-can-fail.md`.
