   `git diff` to prove a test mutation landed *before* believing the result. Use `\r?\n` in patterns.

   separately; CI steps that pipe need `shell: bash` (guarded by `reverify.test.mjs`).

   runner. Corollary: **a capability claim about an instrument is verified by executing the instrument**, not
   by remembering an ad-hoc test that resembled it.
