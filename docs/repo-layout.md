# Layout — bounds-ledger

Moved out of CLAUDE.md 2026-09-04 to bring the loaded context budget back under 60000 bytes (it was 60214). This is reference material: it describes where things live, which is the one part of that file a cold agent can re-derive by listing the tree. The rules that cannot be re-derived — Conventions and Gotchas — deliberately stayed in CLAUDE.md.

## Layout

- `continuity/items.json` — the item ledger (IDs: `G-` goal, `A-` active, `W-` watch). The source of truth for what's open.
- `continuity/traffic.json` — accumulated GitHub traffic samples (W-6). Append-only in effect; the API forgets days older than 14, so this file is the only copy of anything before the current window. Refresh with `npm run traffic` during the steward cadence.
- `docs/reconciliations/` — resolved record discrepancies (the lane's method template lives in #1).
- `docs/findings/` — smaller verified catches.
- `docs/decisions/` — filed decisions awaiting a gate (e.g. A-3's report-upstream draft).
- `docs/daily/<date>-prelaunch.md` — daily reports (needs §3a YAML frontmatter — the r8 linter FAILs without it). **The `-prelaunch` suffix is a HISTORICAL FILENAME, not a lifecycle claim, and is deliberately NOT being renamed** (2026-08-27): David ruled this lane LAUNCHED that day and `lifecycle_stage: launched` is in the frontmatter, but 35+ committed files and every cross-reference point at this path, and the fleet's `REPORT_CONFIGS` resolves to exactly it — renaming buys a tidier name and costs a day of dead references. Read the suffix as "where the reports have always lived"; the frontmatter is the authority on stage. Labelled rather than chased, which is the cheaper fix for a stale-looking label on a changed state.
- `docs/cold-starts/<MT-date>.md` — next-agent primer.
- `docs/lane-brief.md` — **source** for the David-facing brief hosted at `https://skylarkcreations.com/t/lanes/bounds-ledger`. Edit here, then post a bus note so the orchestrator re-ports it.
- `ledger/teorth-optimizationproblems/` — machine **mirror** of the adopted surface: every `constants/*.md` file **plus the repo-root `README.md`** (W-5, 2026-08-10) + `manifest.json` pinning the upstream sha. The count grows when upstream adds a constant; `--check` prints the live figure, so don't write one here. **Why the README is in scope:** the constants files carry the bound tables, but the README is where upstream declares which rows it will STAND BEHIND — a demotion to asterisked-unverified leaves every table byte-identical, so mirroring `constants/**` alone was blind to it (upstream `dee1660`, 2026-08-02: our alarm named three constants files and was silent on the semantically largest change of the day). File maps are keyed by **path as upstream sees it** — the README at the root, each constants file under its own `constants/` prefix. **Do not hand-edit**; refresh only via `--snapshot`.
- `ledger/claims.json` — claim-level value pins (source URL + exact expected string per claim). 11 hand claims (C-1…C-11; C-10 and C-11 are the `nothingAfter` negative pins added 2026-08-11 by A-11, on Wikipedia and `teorth/erdosproblems` respectively; C-8 pins problem 36's entry in `teorth/erdosproblems:data/problems.yaml` — the A-6 second surface; **C-7 + C-9 are the two `manual: true` claims, both on erdosproblems.com/36** — C-7 the bound, C-9 the `last edited 23 January 2026` string) + generated pins (`pin:<file>:U|L`, `generated: true`) covering **every constant file, no exclusions** — read the count from `npm run check`, never from here. **Do NOT re-add a generation skip for a file a hand claim already covers:** the page builds its rows from generated pins alone, so a skip for `1b.md` kept the founding record off the public page from 2026-08-21 until 2026-09-03 while the README called coverage complete. Hand-edit only the hand claims; generated pins are rewritten wholesale by `extract-pins.mjs`.
- `scripts/` — `reverify.mjs` (mirror diff), `check-claims.mjs` (cross-surface claims), `extract-pins.mjs` (regenerates generated pins), `render-state-block.mjs` (**generates README's committed "Current state"; never hand-edit it**; records file count, upstream sha and claim inventory, never a stale live verdict), `check-brief.mjs` (hosted-brief drift; needs the pin), `history-sweep.mjs` (no-secrets gate), `gap-table.mjs` (G-2 ranker; asserts nothing mathematical), `traffic-snapshot.mjs` (W-6 arrival sampler; renders no verdict). Command list and gate wiring live in `AGENTS.md` — do not duplicate them here.
  `check-deferrals.mjs` (A-25) — a deferral carries `deferral: true`, an `expiresOn` and a runnable `releaseTest`. `check-self-attribution.mjs` — a self-attributed CAUSE carries `control:` on the same line, naming what would show the cause is NOT ours; its trigger list is MEASURED against this repo's corpus, and it fires on blame pointed at US while staying silent on blame pointed at upstream — deliberately asymmetric, because nobody challenges you for blaming yourself. Both are wired in `AGENTS.md`; do not restate their wiring here.
  `catch-rate.mjs` — a catch is a GENERATED pin whose `expect` changed. Semantics (ceiling vs count, per-week vs total, the month-of-zeros rule) live in `AGENTS.md` § Commands and the script header; do not restate them here.
  `*.test.mjs` / `--selftest` are network-free and CI-wired; `reverify.test.mjs` prints the live count and fails if a new one lacks a workflow step.
- `search/27b/` — G-2 contribution harness for the Earth-Moon target: `verifier.mjs` (exact DMP planarity + exact chromatic number + certificate check — the DUMB half; model proposes, this code disposes), `selftest.mjs`, `find-sulanke-partition.mjs` + `sulanke-certificate.json` (the reproduced 1980 record — proof the harness can score the known answer), and the search rounds `propose-round.mjs` (r1, propose-then-test) / `round2-grow.mjs` (r2, biplanar by construction) / `round3-seeded.mjs` (r3, edge-budget family scan + growth from a held seed). Certificates are the product; never weaken the verifier to make a candidate pass. **A budget/elimination gate must be proven silent on the record itself** — a gate that flagged Sulanke's own graph would close a family by arithmetic error and every conclusion drawn from it would be worthless (round three).
